## Phase 2 — Physical motion prototype
- [ ] Create minimal .NET/WPF Windows overlay test harness, independent of scheduling.
- [ ] Frame-authored genuine foot-contact walk with translation coupled to gait.
- [ ] Smooth arrival, deceleration, stop, look-up, idle and exit.
- [ ] Real Windows recording at 1.0x and 0.25x, multiple DPI, 20 repeat scenes.
- [ ] Document actual frame pacing, memory and timer cleanup.
- [ ] Reject/iterate if skating, clipping, snap turns or timing issues persist.

**Exit:** User-approved real on-screen locomotion, not a simulation from still images.

## Phase 3 — Natural voice and full response performance
- [ ] Evaluate natural offline voices and Windows TTS fallback.
- [ ] Render/cache title speech during reminder creation/edit.
- [ ] Synchronize expressive mouth states with generated audio cues.
- [ ] Wire Done, Snooze, Hide, Mute and interaction-safe cancellation.
- [ ] Persist reminder state before successful acknowledgement reaction.
- [ ] Confirm ignored reminders become Needs Attention without excessive nagging.

**Exit:** End-to-end reminder scene works smoothly with speech on Windows.

## Phase 4 — Simple, production-minded app
- [ ] Tiny unified app: new/edit/repeat/list/status, voice/pet settings.
- [ ] Reliable local scheduler, tray operation, autostart option, recurrence.
- [ ] Sleep/wake/restart/lock recovery and due-queue handling.
- [ ] Accessibility motion/voice/text controls, minimal help in Settings only.
- [ ] No unrelated dashboard, feeding, statistics, fake actions or dead controls.

## Phase 5 — Release readiness
- [ ] Windows CI and actual installer compile/install smoke checks.
- [ ] Physical Windows tests: fullscreen apps, 100/125/150/200% DPI, multiple displays, keyboard focus, accessibility, offline audio, battery/CPU, crash recovery, high reminder load.
- [ ] Installer/portable package with correct identity and isolated user data paths.
- [ ] Final device-tested video capture and sign-off before describing as a stable release.

## Later
